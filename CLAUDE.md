This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Contents

This repository contains a single document: `magnfica-humanitas.md` — the encyclical letter *Magnifica Humanitas* of Pope Leo XIV, "On Safeguarding the Human Person in the Time of Artificial Intelligence."

It is a text document, not a software project. There are no build steps, dependencies, tests, or executables.

## Document Structure

The encyclical is organized in five chapters:

1. **A Dynamic Approach Faithful to the Gospel** — Church Social Doctrine from Leo XIII to the present
2. **Foundations and Principles of Social Doctrine** — human dignity, common good, subsidiarity, solidarity
3. **Technology and Dominance** — the technocratic paradigm, AI governance, transhumanism, Christian humanism
4. **Safeguarding Humanity at a Time of Transformation** — truth, work, freedom in the digital age
5. **The Culture of Power and the Civilization of Love** — war, weapons and AI, multilateralism, peacebuilding
